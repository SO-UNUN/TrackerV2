ส่วนที่ 2หลักการ Simple Harmonic Motion

สมการ SHM พื้นฐาน

x(t) = A·cos(ωt + φ) A = amplitude (cm), ω = 2πf (rad/s), φ = phase (rad)

SHM ของมวลติดสปริง

ω₀ = √(k/m),  T = 2π√(m/k) k = spring constant (N/m), m = mass (kg)

Damped Harmonic Oscillator

เมื่อมีแรงต้าน การสั่นจะค่อยๆ ลดลง:

x(t) = A·e^(-γt)·cos(ωt + φ) + offset γ = damping coefficient (1/s), ζ = γ/ω₀ = damping ratio

Quality Factor (Q)

Q = ω / (2γ) Q สูง = damping ต่ำ การสั่นนาน
📚
การตีความ Q: Q ≈ จำนวนรอบที่ amplitude ลดเหลือ 37% (1/e)
Q = 10 — damping พอประมาณ | Q = 100 — น้อยมาก (tuning fork) | Q < 1 — overdamped

ส่วนที่ 6การตีความ FFT และ Damped Fit

📊 FFT Spectrum

FFT แปลงสัญญาณ time domain → frequency domain แสดง amplitude ที่แต่ละ frequency

🟢 Single peak ชัด — SHM แบบเดียว frequency ตรงกับ peak counting

🟡 Multiple peaks — มี harmonics หรือ multiple modes

🔴 Spectrum กระจาย — noise สูง หรือไม่ใช่ periodic motion

🌊 Damped Oscillator Fit

x(t) = A·e^(-γt)·cos(ωt + φ) + offset
การตีความ R²

🟢 R² ≥ 0.99 — Excellent, damped SHM แท้

🔵 R² ≥ 0.95 — Good ใช้ได้ในงานทั่วไป

🟡 R² < 0.95 — มี deviation จาก SHM

การตีความ Damping Ratio ζ

ζ < 1: Underdamped — มีการสั่น (ปกติของสปริง)

ζ = 1: Critically damped — กลับสมดุลเร็วสุด ไม่สั่น

ζ > 1: Overdamped — กลับสมดุลช้า ไม่สั่น

🔬 Spring Constant Calculation

k = (2πf₀)²·m f₀ = natural frequency, m = mass (kg)

เปรียบเทียบกับ static method (แขวนน้ำหนัก + วัดระยะยืด):

k = mg / Δx g = 9.81 m/s², Δx = ระยะยืด
💡
การทดลองที่น่าสนใจ:
1. เทียบ k จาก SHM (dynamic) vs static method
2. ศึกษา Q ที่ amplitude ต่างๆ
3. เปลี่ยนตัวกลาง (อากาศ vs น้ำ) ดู damping ratio
4. ใช้สปริงต่างๆ สร้าง calibration table
